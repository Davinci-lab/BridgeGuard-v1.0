# Security Policy

## Public Repository Boundary

This repository contains only public demonstration material. It must not contain:

- secrets, credentials, tokens, keys, RPC URLs, webhook URLs, or private endpoints;
- executable product source code;
- proprietary risk formulas, production policies, or connector logic;
- exploit payloads or operational instructions that enable offensive use;
- customer data, pilot data, logs, reports, screenshots with identifiers, or internal infrastructure details.

## Reporting A Concern

If you believe sensitive information has been published, open a private security advisory or contact the maintainers directly. Do not disclose suspected secrets, exploit details, or customer information in a public issue.

## Defensive Use Notice

BridgeGuard is designed for defensive monitoring, simulation, audit support, and risk review. It is not a substitute for independent audits, incident response planning, secure bridge design, or production monitoring controls.
